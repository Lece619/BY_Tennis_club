회원
이름이나 "관리"를 누르면 회원 카드가 열리고, 휴식·삭제·관리자 지정은 카드 안에 있습니다.
건의사항
설정
이름 표시 방식 (모든 회원 화면에 적용)
예:
모임 상세의 참가자 명단, 대진표, 결과 표에 적용됩니다. 다른 회원 화면에는 다음에 모임을 열 때 반영됩니다.
회비 안내 · 입금 계좌
홈의 "회비" 카드에 보입니다. 안내 글은 누구나, 입금 계좌는 승인된 회원(게스트 제외)만 볼 수 있고 누르면 복사됩니다.
회칙 수정 (대표만)
줄 앞에 "제n장"은 제목, "• "는 조항, "◦ "와 "▪ "는 하위 항목으로 표시됩니다. 저장하면 모든 회원 화면에 바로 반영됩니다.
관리자 코드 변경 (대표만)
관리자로 올리고 싶은 회원에게 이 코드를 알려 주면, 그 회원이 내 정보 → 관리자 인증에 입력해 관리자가 됩니다. 회원 목록의 "관리자 지정" 버튼으로 직접 올려도 됩니다. 6자 이상.
대표 코드 변경 (대표만)
대표 자리를 넘길 때 쓰는 비밀 코드입니다. 평소에는 회원 목록의 "대표 넘기기" 버튼을 쓰면 되고, 이 코드는 대표가 자리를 비웠을 때를 대비한 비상용입니다. 이 코드를 아는 관리자가 내 정보 → 대표 인증에 입력하면 그 사람이 대표가 되고, 기존 대표는 관리자가 됩니다. 아는 사람에게만 알려 주세요. 6자 이상.
